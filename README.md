## ÄTA-logg

En logg som visar ÄTA-jobb som man gör eller har gjort. Man ska kunna se godkända och eh godkända. Framöver kommer vi att lägga till fakturerade och betalda ÄTA-påoster med som kommer sorteras separat.

## Nuvarande funktioner

- registrera ÄTA
- visa den som ett kort
- ändra status åt båda hållen
- färgmarkera status
- spara data i local storage
- läsa tillbaka sparad data till arrayen
